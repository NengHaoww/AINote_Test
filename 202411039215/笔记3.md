# 【3月28日广东省教育评估协会年会参会纪要】

- 3月28日，广东省教育评估协会第三届第二次会员代表大会暨2026年学术年会在广州举行。我校党委常委、副校长郑耿忠教授作为副会长单位代表带队参会，并在大会主论坛主持议程，同时我校被授予“副会长单位”牌匾。

图片：{"name": "郑耿忠发言照片", "url": "https://example.com/photo2.jpg"}  
- 当日下午，郑耿忠在高等教育论坛作题为《精神铸魂·交叉赋能·评价驱动——以“人才班”为抓手的拔尖创新人才培养实践与评估探索》的主旨分享。  
- 他介绍我校依托韩愈师道、黄旭华科学家、饶宗颐学术精神，创设“韩愈卓师班”“黄旭华创新班”“饶宗颐国学班”，构建“一班一特色、一班一模式”的分类培养体系。  
- 实践中，通过精神铸魂、交叉赋能、四维评估体系，形成“评价—反馈—改进—提升”闭环机制，破解地方院校同质化难题，打造可复制的“韩师样板”。  
- 该探索获与会专家高度评价，为应用型本科院校提供新路径。

# 【3月27日英氏控股来校交流暨科研平台揭牌活动纪要】  
- 3月27日，英氏控股集团股份有限公司（简称英氏控股）总裁助理、技术总监戴志勇一行五人来我校交流，受到我校党委副书记、校长刘海春，党委常委、副校长陈海忠的热情接待。校企双方在广东省粤东药食资源功能物质与健康产品研究重点实验室举行了两个共建科研平台的揭牌仪式，活动由生命科学与食品工程学院院长朱慧主持。

- 陈海忠指出，英氏控股作为国内婴幼儿辅食领域的头部企业，拥有丰富的行业资源和先进的技术设备，能够为校企合作提供优质条件。他强调我校在科研创新与人才培养方面的责任和态度，期待通过产学研合作，充分发挥我校科研优势，为儿童健康产业发展注入新动能。戴志勇表示，英氏控股将依托企业的市场资源与技术需求，与我校携手推进科研成果转化，实现校企共赢。

- 陈海忠、科研部部长张晖英、生命科学与食品工程学院副院长郑玉忠与戴志勇、英氏控股经理刘阳、李蕾共同为“广东省粤东药食资源功能物质与健康产品研究重点实验室（分中心）—AI+药食资源智能发酵健康功能产品研究中心”“广东省粤东食品加工与安全控制工程技术研究中心（分中心）—药食资源发酵与食品生物AI绿色智造工程研究中心”揭牌。

- 交流环节，双方围绕合作模式、人才联培、成果转化等展开深入探讨。

- 戴志勇一行还先后参观了黄旭华功勋纪念馆、食品科技大楼实验室和生物标本馆，实地了解我校办学特色、科研平台及育人成果。

- 生命科学与食品工程学院相关负责人表示，此次交流活动实现了预期目标，加深了我校与英氏控股之间的交流互通，双方将以两平台为依托，汇聚校企优势资源，在药食资源功能研究与食品加工技术创新领域开展深度合作，为粤东地区乃至全国的健康食品产业高质量发展贡献力量。

- 计算机与信息工程学院、生命科学与食品工程学院相关负责人及科研骨干参加了活动。
